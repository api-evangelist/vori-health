# Vori Health

> Vori Health is a nationwide, virtual-first musculoskeletal (MSK) medical practice headquartered in Nashville, Tennessee, founded in 2020 by neurosurgeon Dr. Ryan Grant (co-founder, CEO) and orthopedic surgeon Dr. Mary O'Connor (co-founder, Chief Medical Officer). It treats back, neck and joint pain with physician-led integrated care teams — board-certified physiatrists licensed in all 50 states working alongside physical therapists, registered dietitians and health coaches — delivered virtually and in person through a patient mobile and web application, and sold to employers, health plans, benefits consultants and risk-bearing provider groups.

## Developer surface

Vori Health publishes **no public API, no developer portal, and no machine-readable contract**. This section records what was probed on 2026-09-04 so an agent does not repeat the search.

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, gRPC/Protobuf or WSDL is published on any host in the vorihealth.com estate.
- No `/.well-known/` document is served on `vorihealth.com`, `www.vorihealth.com`, `app.vorihealth.com` or `api.vorihealth.com` — no `security.txt`, `openid-configuration`, `oauth-authorization-server`, `api-catalog`, `ai-plugin.json` or A2A agent card.
- No hosted MCP server, no `llms.txt` published by the company, no Postman workspace, no first-party SDK on npm, PyPI, RubyGems, crates.io, NuGet, Maven Central or pkg.go.dev, and no GitHub organization (`github.com/vorihealth` and `github.com/vori-health` both 404).
- `api.vorihealth.com` resolves to an AWS API Gateway (`d-n836o9gegb.execute-api.us-east-1.amazonaws.com`) that answers `403 {"message":"Missing Authentication Token"}` on every path. It is the private backend for the patient application, not a documented developer API.
- `app.vorihealth.com` is a client-rendered Angular application that returns the same HTML shell with HTTP 200 for every path — treat any 200 from that host as a catch-all, not a document.
- `partners.vorihealth.com` is a Webflow site behind a password gate (HTTP 401). It is a partner marketing page, not a developer surface.
